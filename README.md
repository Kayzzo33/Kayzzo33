## 💼 Featured Work

**AutoSync** — Complete workshop management platform (largest project)
End-to-end system for large auto repair shops: open/close service orders, vehicle registry, inventory, and a marketing module that collects customer data for targeted follow-ups. Built to run a workshop's entire daily operation.

**OnzyEstuda** — AI-powered study platform
Uses AI + RAG to help people study: summarizes content, turns quick notes into organized summaries, and reads/summarizes PDFs automatically.

**Umami** — Restaurant ordering & management system
Customer-facing ordering screen plus an admin panel for order management, inventory control, and revenue tracking — a complete operational system for a burger restaurant.

**Photo Sales Platform** — E-commerce for photographers
Photographers share album links, clients browse and purchase photos directly, with an operational panel built around the photographer's workflow.

**Multi-tenant CRM** — AI-powered CRM (zPro-style)
Full CRM built to serve multiple companies from one platform, with AI-assisted features baked in.
